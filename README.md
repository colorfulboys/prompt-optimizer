# 简盒 JianHeBox · 提示词优化器

> 🚀 **免费在线 AI 提示词优化工具** —— 一键优化你的 Prompt，支持多模型对比测试，本地数据持久化，零门槛提升 AI 回答质量。

🌐 立即访问：[**jianhebox.cn**](https://jianhebox.cn) ｜ 英文版：[jianhebox.com](https://jianhebox.com)

## ✨ 核心功能

- 🎯 **智能优化** —— 基于 DeepSeek-V3 / GPT-4o / Claude 一键优化你的 Prompt，效果立竿见影。
- 🔄 **多模型对比** —— 同一 Prompt 在多个模型下生成结果，横向对比选出最佳。
- 💾 **本地数据持久化** —— 历史记录、收藏夹、变量管理全部存入浏览器 IndexedDB，**数据不上传服务器**。
- ⚡ **开箱即用** —— 基于 Vue 3 + TypeScript 构建，部署在 Cloudflare Pages，**打开网页就能用**。
