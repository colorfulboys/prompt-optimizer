🔧 Advanced Techniques

1. Two-Pass Encoding

Standard (1-pass): Original → encode → output

Two-pass:

  1. Pass 1: analyze (find complex scenes)
  2. Pass 2: smart encode with analysis

Result: 20-30% smaller file, better quality. But 2x slower.

2. Dynamic Bitrate (CBR vs VBR)

ModeDescriptionUse Case
CBRFixed bitrate throughoutLive streaming
VBRDynamic (low for simple, high for complex)90% of cases

JianHeBox defaults to VBR.

3. Cut First, Compress Second

30-min recording but only 5 min useful? Cut first → compress. File size can drop 80%+.

❌ Common Misconceptions

Myth 1: Higher Resolution is Always Better

Wrong! 4K on phone screen is indistinguishable from 1080p but file is 4x larger.

Myth 2: Lower Bitrate is Always Better

Wrong! 1080p at <2 Mbps looks bad. Find the "acceptable quality" minimum bitrate.

Myth 3: H.265 is Always Better than H.264

Not always! H.265 compatibility is worse. Use H.265 for modern devices, H.264 for compatibility.

Myth 4: Online Compression is Safe

Wrong! Files may be permanently stored on servers. For privacy videos (family, meetings), use local processing.
