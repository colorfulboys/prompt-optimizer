🎯 9 Practical Tips

Tip 1: Define Role Clearly

DeepSeek is highly sensitive to "who you are".

❌ Wrong:

Help me write an article about health

✅ Right:

You are a senior nutritionist with 20 years of clinical experience.
Write an article about "maintaining healthy diet under high-pressure work" for 30-40 year-old female office workers.

Requirements:
- 800 words
- Easy to understand, no jargon
- Include 3 practical tips
- End with an interactive question

Format: Markdown

Effect: Output quality 3-5x better.

Tip 2: Detailed Task Description

DeepSeek prefers specific tasks.

❌ Wrong:

Help me optimize this prompt

✅ Right:

You are an AI prompt engineer.
Help me optimize the following prompt with these requirements:
1. Add 4 key elements (role/task/context/format)
2. Make output more structured
3. Include specific examples
4. Keep under 200 words

My original prompt: "Help me write an article about skincare"

Tip 3: Chain of Thought (English version)

DeepSeek responds well to "think step by step".

Please think step by step:
1. Analyze the core of the problem
2. List possible solutions
3. Compare pros and cons of each
4. Give recommendation

Problem: [your problem]

Tip 4: Few-Shot Examples

DeepSeek is sensitive to examples.

Translate English to Chinese:

Examples:
- "Hello world" → "你好世界"
- "How are you?" → "你好吗？"
- "I love programming" → "我爱编程"

Now translate:
- "The quick brown fox jumps over the lazy dog"
- "Practice makes perfect"

Effect: With examples, accuracy improves 40%+.

Tip 5: Structured Output

DeepSeek excels at structured content.

Output in this format:

【Core Insight】
(1-2 sentences)

【Key Points】
1. ...
2. ...
3. ...

【Use Cases】
- ...

【Notes】
- ...

【Examples】
(concrete examples)

Topic: [your topic]

Tip 6: Specify Output Length

DeepSeek defaults to long Chinese output. Control with specific ranges.

Summarize this article in 100-150 words:

[article content]

Or:

Write in 3 paragraphs, each 50 words, a brief summary.

Tip 7: Negative Prompts

Tell DeepSeek what NOT to do.

Write an article recommending "AI tools".

Requirements:
- List 5 tools
- Each tool: 1 specific use case

DO NOT:
- Use empty phrases ("AI makes life better")
- Repeat the title
- List too many features (1 use case per tool)
- Use emoji decorations

Tip 8: Role Dialogue

DeepSeek is particularly strong at role dialogue.

You are [role], I have questions for you.

Role setup:
- [identity]
- [personality]
- [background]

Your answers should:
- Consistent tone
- Stay in character
- Give specific advice

Now begin:
[your question]

Tip 9: Iterative Optimization

DeepSeek supports multi-turn dialogue. Iterate to improve.

Turn 1: "Write a short article on remote work."

Turn 2: "Make the opening more engaging (add hook)."

Turn 3: "Add 3 specific remote work tool recommendations."

Turn 4: "Reorganize structure with subheadings for clarity."

Effect: Iterative approach gives 5x better quality than one-shot.

🎯 6 Practical Scenarios

Scenario 1: Writing Blog Posts

You are a blog writer, audience is [audience].

Write a 2000-word blog post:
- Topic: [topic]
- Style: conversational, with stories and insights
- Structure: hook + 5 points + closing CTA
- Keyword: [keyword] appears 3-5 times
- Emoji: occasional, not every paragraph

Scenario 2: Xiaohongshu

You are a Xiaohongshu writer.

Write a Xiaohongshu post:
- Topic: [topic]
- Title: under 18 chars, with emoji
- Body: 300-500 words, 3-5 paragraphs
- Style: conversational, like talking to a friend
- Keyword: [keyword] 3 times
- Closing: CTA to comment

Scenario 3: Code

You are a [Python/Java/...] senior engineer.

Write:
- Function: [description]
- Input: [example]
- Output: [example]

Requirements:
- Comments (English)
- Exception handling
- Unit tests
- Code style: PEP 8

Scenario 4: Translation

Translate this [English] to [Chinese].

Requirements:
- Preserve original meaning
- Smooth and natural
- Accurate technical terms
- Mark key terms in English at the end

[content]

Scenario 5: Data Analysis

Analyze this data:

[data CSV/JSON/text]

Requirements:
1. Basic info (rows, fields, missing values)
2. Main trends / anomalies
3. Key insights (3-5 points)
4. Action recommendations

Output: Markdown table + text explanation

Scenario 6: Learning New Concepts

I want to deeply understand [concept].

Please:
1. Explain in 1 sentence
2. Give 1 example
3. List 3 common misconceptions
4. Recommend 3 learning resources (book/website/video)
5. Give 3 "Feynman technique" self-test questions

⚠️ DeepSeek Limitations

Limitation 1: No Web Access

DeepSeek cannot:

  • Get real-time news
  • Search latest data
  • Access external links

Alternative: Use ChatGPT (web-enabled) or Metaso AI search.

Limitation 2: English Slightly Weaker

DeepSeek is slightly weaker than GPT-4 in English (especially creative writing).

Suggestion: Use ChatGPT for English tasks.

Limitation 3: Occasional Hallucinations

DeepSeek sometimes fabricates facts.

Solution:

  • Verify key facts (Google)
  • Ask DeepSeek to cite sources
  • Use prompt: "Be cautious, don't fabricate"
