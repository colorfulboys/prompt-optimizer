📖 FCPXML Basics

What is FCPXML?

FCPXML = Final Cut Pro XML = Apple's official subtitle/timeline exchange format.

  • Not a video file — it's XML text (open in any text editor)
  • Contains: timestamps, text, styles, track info
  • Cross-software: Pr / DaVinci / JianYing Pro all recognize it
  • Lossless: no frame or subtitle loss in conversion

FCPXML Structure (simplified)

<?xml version="1.0" encoding="UTF-8"?>
<fcpxml version="1.11">
  <resources>
    <format id="r1" name="FFVideoFormat1080p25"/>
  </resources>
  <library>
    <event name="My Video">
      <project name="Project 1">
        <spine>
          <title name="Subtitle Track" lane="1">
            <text>
              <text-style ref="ts1">Hello, welcome to JianHeBox</text-style>
            </text>
          </title>
        </spine>
      </project>
    </event>
  </library>
</fcpxml>

🎯 4 Real-World Scenarios

Scenario 1: JianYing Subtitles → FCPXML

Background: Many vloggers create subtitles in JianYing because:

  • JianYing's auto-subtitle recognition is more accurate than Pr/FCPX (especially Chinese)
  • JianYing has more text styles (bubbles, shake, rainbow text)

But JianYing's subtitles can't be used directly in FCPX (incompatible formats).

Step-by-step:

  1. Export from JianYing:
    • JianYing → Select video → "Text" → "Recognize Subtitles"
    • After recognition → Click "···" on subtitle track → "Export Subtitles"
    • Choose SRT format → Save locally
    Tip: Don't export JianYing project files (.draft) — they can't convert to FCPXML
  2. Convert with JianHeBox:
    • Open jianhebox.cn/fcpxml
    • Drag in the exported SRT file
    • Input: SRT · Output: FCPXML
    • Click "Convert" → Download output.fcpxml
  3. Import to FCPX:
    • Open Final Cut Pro
    • File → Import → XML (or ⌘⌥I)
    • Select the .fcpxml file
    • Subtitles appear on the timeline with perfect time alignment

Scenario 2: Premiere Pro Subtitles → FCPXML

  1. Pr → Captions panel → Select all subtitles
  2. Captions → Export Captions → SRT
  3. Same conversion steps as Scenario 1

❓ FAQ

Q1: Subtitles look garbled after conversion?

Cause: Original file encoding is not UTF-8 (common for Windows-exported SRT).

Fix: JianHeBox auto-converts encoding. If still garbled, use Notepad → "Save As" → Encoding: UTF-8.

Q2: Subtitles positioned wrong after FCPX import?

Cause: FCPXML lane attribute specifies track position.

Fix:

  • JianHeBox default: lane="1" (main subtitle track)
  • Want subtitles above video: lane="-1"
  • Want double-row subtitles: lane="2"

Q3: Slow conversion?

JianHeBox processes in browser. For long subtitle files (5000+ entries), split into batches. Max 3000 subtitles per conversion is stable (2-hour video).

Q4: Styles lost after conversion?

Cause: Source files (e.g., SRT) don't contain style info.

Fix: JianHeBox offers 4 preset styles applied uniformly. Or use JianYing/Pr's "Export with Styles" option.
