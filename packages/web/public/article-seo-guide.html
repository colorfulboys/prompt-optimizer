📚 Week 1：SEO 基础 + 站长工具

1.1 什么是 SEO？

SEO = Search Engine Optimization（搜索引擎优化）

目标：让网站在百度 / Google 搜索结果里**排名靠前**，获得免费自然流量。

1.2 百度 vs Google

搜索引擎国内市场份额特点
百度~70%中文搜索第一
Google海外主流国际化
必应~10%英文搜索
搜狗~5%腾讯系

1.3 注册站长工具

  • 百度站长：ziyuan.baidu.com
  • Google Search Console：search.google.com/search-console

1.4 验证网站

  1. 添加网站（域名）
  2. 选验证方式（推荐 HTML 文件）
  3. 下载验证文件，上传到网站根目录
  4. 点验证
  5. 提交 sitemap.xml

📚 Week 2：关键词研究

2.1 关键词是什么？

用户在搜索引擎输入的词。例如：「PDF 转 Word 在线」

2.2 关键词分类

类型搜索量竞争度例子
核心词高高「PDF 转 Word」
长尾词低低「PDF 转 Word 在线免费保留格式」
疑问词中低「PDF 转 Word 怎么操作」
场景词中中「PDF 转 Word 学术论文」

2.3 关键词工具

  • 百度指数：index.baidu.com（免费）
  • 5118：5118.com（付费）
  • 爱站：aizhan.com（免费）
  • Google Keyword Planner：ads.google.com（免费）
  • Ahrefs：ahrefs.com（付费，海外最强）

2.4 关键词选择原则

  • ✅ 搜索量 > 100/月（太少没意义）
  • ✅ 竞争度低（新站优先长尾词）
  • ✅ 转化率高（用户用你的工具能赚钱）
  • ✅ 与网站相关（不要做无关词）

2.5 长尾词策略

新站**不能做**「PDF 转 Word」这种核心词（竞争激烈）。

应该做：

  • 「PDF 转 Word 保留格式 95%」（具体场景）
  • 「PDF 转 Word 在线免费」（价格相关）
  • 「PDF 转 Word 工具推荐」（疑问词）

📚 Week 3：站内优化

3.1 Title（标题）

最重要的 SEO 因素之一。

公式：核心关键词 + 修饰词 + 品牌名

例：

  • 好：PDF 转 Word 在线免费保留格式 - 简盒
  • 差：首页 - 简盒

3.2 Description（描述）

搜索结果里显示的 1-2 行文字。

建议：

  • ✅ 包含主关键词 1-2 次
  • ✅ 写出价值主张
  • ✅ 120-160 字

3.3 H1 / H2 / H3

  • H1：每页 1 个，包含主关键词
  • H2：分章节，包含长尾词
  • H3：子章节

3.4 内容质量

Google 2026 算法：

  • ✅ E-E-A-T：经验、专业、权威、可信
  • ✅ 原创 ≥ 80%
  • ✅ 字数 ≥ 500 字（最好 1500+）
  • ✅ 图文并茂

3.5 内链

站内文章互相链接，让搜索引擎知道结构：

PDF 转 Word
PDF 转 Excel

3.6 Schema（结构化数据）

用 JSON-LD 给搜索引擎提供信息：

{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "PDF 转 Word 教程",
  "author": "简盒",
  "datePublished": "2026-09-14"
}

3.7 图片优化

  • ✅ 文件名：用描述性名字（`pdf-to-word.png` 而非 `IMG_1234.png`）
  • ✅ Alt 标签：描述图片内容
  • ✅ 压缩：< 200 KB
  • ✅ WebP 格式：比 JPG 小 30%

📚 Week 4：外链 + 内容

4.1 外链是什么？

其他网站链接到你的网站 = "背书"。搜索引擎认为这是"信任投票"。

4.2 外链渠道

类型难度效果
友情链接交换低中等
知乎 / 小红书 / 公众号中高
新闻投稿高很高
购买外链⚠️ 风险短期有效，长期被惩罚

4.3 内容策略

持续输出是 SEO 最重要的因素：

  • ✅ 每周 2-3 篇原创
  • ✅ 每篇 1500+ 字
  • ✅ 围绕 1-2 个关键词
  • ✅ 有真实案例 / 数据

📊 关键指标

收录指标

  • 索引量：百度 / Google 收录了多少 URL
  • 覆盖率：提交 URL 中被收录的比例

排名指标

  • 关键词排名：你的网站在某个关键词的位置
  • 展现量：在搜索结果出现多少次
  • 点击量：用户点了几次

流量指标

  • PV / UV：浏览量 / 独立访客
  • 跳出率：只看了 1 页就走的比例
  • 停留时间：用户在网站待多久

⚠️ 不要做的事

  • ❌ 关键词堆砌（百度算法会惩罚）
  • ❌ 购买大量外链（百度会降权）
  • ❌ 复制他人内容（原创度低 = 排名靠后）
  • ❌ 隐藏文字 / 链接（黑帽 SEO，必被惩罚）
  • ❌ 频繁改版 / 改标题（沙盒期会延长）
