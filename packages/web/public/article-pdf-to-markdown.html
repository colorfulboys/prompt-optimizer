📖 基础概念

Markdown 是什么？

Markdown = 纯文本 + 简单标记语法：

# 标题
粗体 *斜体*
链接
!图片
> 引用
- 列表
1. 编号
\代码\
\\\
代码块
\\\

PDF 转 Markdown 的难点

| PDF 元素 | Markdown 等价 | 难度 |

|---|---|---|

| 标题 | # H1 | ⭐ 简单 |

| 段落 | 普通文本 | ⭐ 简单 |

| 列表 | - item | ⭐⭐ 中等 |

| 表格 | \| \| \| | ⭐⭐⭐ 难 |

| 图片 | !alt | ⭐⭐ 中等 |

| 数学公式 | $LaTeX$ | ⭐⭐⭐⭐ 难 |

| 代码块 | ` | ⭐⭐ 中等 |

| 引用 | > quote | ⭐ 简单 |

关键：AI 识别准确率 85-95%，公式和表格最难。

🔧 高级技巧

1. 处理数学公式

PDF 转 Markdown，公式转换的 3 个层次：

| 层次 | 准确率 | 输出 |

|---|---|---|

| 简单公式（a²+b²=c²） | 95%+ | LaTeX |

| 中等公式（积分、矩阵） | 80-90% | LaTeX（部分需修正）|

| 复杂公式（多行、嵌套） | 50-70% | 可能丢失 |

修正方法：用 Mathpix（学术专业）或手动修正。

2. 表格保留

PDF 表格转 Markdown 的难点：

PDF 表格 → 智能识别行列 → 生成 Markdown 表格

简盒用 AI 模型识别表格边界，准确率 80-85%。复杂合并单元格可能丢失。

3. 图片处理

转换后图片处理：

原 PDF 图片 → 提取 → 嵌入 Markdown

简盒默认自动提取图片并嵌入 Markdown（用 base64 编码）。

注意：如果 PDF 图片很多，生成的 .md 文件会很大（> 10MB）。

4. 保留原页码

转换时勾选「保留页码注释」：

[第 12 页]

# 标题

正文...

用途：方便对照原 PDF 引用。

⚠️ 常见问题

Q1：转换后中文乱码？

原因：PDF 字体未嵌入

解决：

  • 用 Adobe Acrobat 重新导出 PDF（嵌入所有字体）
  • 再转换

Q2：公式转换是图片不是 LaTeX？

原因：PDF 公式是图片，不是文本

解决：

  • 用 Mathpix（专业公式识别）
  • 或手动转 LaTeX

Q3：表格错位？

原因：原 PDF 表格不规范

解决：

  • 转换后手动检查表格
  • 用 Markdownlint 验证

Q4：扫描版 PDF 转换失败？

原因：扫描版是图片，没有文字层

解决：

  • 简盒支持 OCR，勾选启用
  • OCR 准确率 70-85%，重要文档需核对

Q5：图片丢失？

原因：默认未保留图片

解决：

  • 简盒默认保留图片
  • 检查「保留图片」选项
