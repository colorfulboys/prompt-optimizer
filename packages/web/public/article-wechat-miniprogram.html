2026 年，微信小程序依然是国内最重要的前端生态之一。如果你想：

💻 Day 1：第一个 Hello World

步骤

  1. 打开微信开发者工具
  2. 「小程序」→「+」→ 选目录
  3. 填 AppID（没 AppID 选「测试号」）
  4. 点「确定」
  5. 看默认 demo → 点「编译」→ 看模拟器

最小目录结构

miniprogram/
├── app.js          # 小程序逻辑
├── app.json        # 全局配置
├── app.wxss        # 全局样式
├── pages/
│   └── index/
│       ├── index.js
│       ├── index.json
│       ├── index.wxml
│       └── index.wxss
└── sitemap.json    # 搜索引擎收录

💻 Day 2-3：基础语法（30 分钟）

WXML（类似 HTML）


  {{ message }}

WXSS（类似 CSS）

.container {
  padding: 20rpx;
  text-align: center;
}

button {
  background: #07c160;
  color: white;
  border-radius: 8rpx;
}
💡 rpx 单位：750rpx = 屏幕宽度，自适应

数据绑定 + 事件

// JS
Page({
  data: {
    count: 0,
    name: '简盒'
  },
  onTap() {
    this.setData({ count: this.data.count + 1 })
  }
})

💻 Day 4：云开发（数据库 + 云函数）

微信云开发 = 后端 + 数据库 + 云函数，不用买服务器。

5 步启用云开发

  1. 开发者工具 → 点「云开发」
  2. 「开通」
  3. 创建环境（test / prod 各一个）
  4. 等 2 分钟初始化
  5. 获得 envId

云数据库示例

// 1. 初始化
wx.cloud.init({ env: 'test-xxxxx' })

// 2. 取数据
const db = wx.cloud.database()
db.collection('todos').where({
  _openid: '{openid}'
}).get().then(res => {
  console.log(res.data)
})

💻 Day 6：API + 登录 + 支付

登录（2 行代码）

wx.login({
  success: res => {
    console.log(res.code)  // 发给后端换 session
  }
})

调用 API

wx.request({
  url: 'https://api.example.com/data',
  method: 'GET',
  success: res => console.log(res.data)
})

支付（需要企业主体）

个人主体不能开通支付。找有营业执照的同事帮忙。

💻 Day 7：发布上线

  1. 开发者工具 → 「上传」
  2. 填版本号（如 1.0.0）
  3. 登录 mp.weixin.qq.com
  4. 「版本管理」→ 找到刚才上传的版本
  5. 「提交审核」
  6. 等 1-3 天通过
  7. 「发布」→ 上线

⚠️ 常见问题

Q1：没 AppID 能不能开发？

答：能。选「测试号」，但不能上线。

Q2：个人能上线小程序吗？

答：能，但不能带支付 / 商业功能。工具类、资讯类没问题。

Q3：发布需要资质吗？

答：

  • 个人：身份证 + 微信认证（免费）
  • 企业：营业执照 + 对公账户认证（300 元/年）

Q4：用什么 IDE？

答：

  • 官方：微信开发者工具（必备）
  • 第三方：VS Code + 插件（推荐）

Q5：多久能学会？

答：

  • 有 JS 基础：3-5 天
  • 零基础：7-14 天
  • 做出第一个完整小程序：7 天

Q6：可以接私活吗？

答：可以。简单小程序 1000-5000 元，复杂 1-5 万元。
