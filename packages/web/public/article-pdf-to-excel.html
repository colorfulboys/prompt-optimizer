💡 高级技巧

1. 转换后数字还是文本？

解决：

  • 选中数字列 → 「数据」→「分列」→「下一步」→「下一步」→「文本」→「完成」
  • 然后用 VALUE() 函数转换：=VALUE(A1)

2. 表格边框丢了？

解决：

  • 选中所有数据 → 「开始」→「边框」→ 选「所有框线」
  • 或按 Ctrl + A → Ctrl + Shift + L（加表格样式）

3. 多列错位了？

原因：PDF 原表格用了合并单元格

解决：

  • 转换前在 PDF 里取消合并单元格
  • 或转换后手动调整列宽

4. 文件太大转换慢？

解决：

  • PDF > 100 MB：建议先 PDF 压缩
  • > 500 MB：分章节转换
  • > 1000 页：分批处理

⚠️ 常见问题

Q1：转换后表格全部挤在一列？

原因：PDF 表格没有明确边框

解决：简盒 → 勾选「启用 OCR 强制识别表格」

Q2：扫描 PDF 转换是空的？

原因：扫描件是图片，需要 OCR

解决：选「PDF 转 Excel (OCR)」模式

Q3：Excel 打开提示"文件损坏"？

解决：

  • 用 WPS 打开试一下
  • 或下载后重新打开一次
  • 90% 情况是 Excel 版本问题

Q4：转换慢/卡死？

解决：

  • 关闭其他浏览器标签页
  • PDF 超过 100 页：分批
  • 扫描版需要 30 秒-2 分钟（OCR 较慢）
