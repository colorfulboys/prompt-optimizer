🎯 9 个 DeepSeek 实战技巧

技巧 1：明确身份

原理：DeepSeek 对"你是谁"非常敏感。

❌ 错误：

帮我写一篇关于健康的文章

✅ 正确：

你是中国营养学会首席专家，有 20 年临床营养经验。
请给 30-40 岁白领女性写一篇关于"高压工作下保持健康饮食"的公众号文章。

效果对比：输出质量提升 3-5 倍。

技巧 2：详细任务描述

DeepSeek 偏好具体任务。

❌ 错误：

帮我优化这段提示词

✅ 正确：

你是 AI 提示词工程师。
请帮我优化以下提示词，要求：
1. 增加 4 大要素（角色/任务/上下文/格式）
2. 让 AI 输出更结构化
3. 加入具体示例
4. 控制在 200 字以内

我的原提示词是："帮我写一篇关于护肤的文章"

技巧 3：中文 Chain of Thought（链式思考）

DeepSeek 中文链式思考效果特别好。

Prompt：

请一步步思考：
1. 分析问题的核心
2. 列出可能的解决方案
3. 比较每个方案的优缺点
4. 给出推荐方案

问题：[你的问题]

DeepSeek 中文推理 比英文模型好，因为：

  • 训练数据中文占比大
  • 中文语法更精确
  • 推理能力在中文场景下发挥更好

技巧 4：Few-Shot（给示例）

DeepSeek 对示例非常敏感。

❌ 无示例：

把英文翻译成中文。

✅ 有示例：

请将以下英文翻译成中文：

示例：
- "Hello world" → "你好世界"
- "How are you?" → "你好吗？"
- "I love programming" → "我爱编程"

现在翻译：
- "The quick brown fox jumps over the lazy dog"
- "Practice makes perfect"

效果：有示例时输出准确率提升 40%+。

技巧 5：结构化输出

DeepSeek 擅长输出结构化内容。

Prompt：

请按以下格式输出：

【核心观点】
（1-2 句话）

【关键要点】
1. ...
2. ...
3. ...

【适用场景】
- ...

【注意事项】
- ...

【示例】
（具体例子）

主题：[你的主题]

优势：DeepSeek 会精确遵循格式（比 GPT-4 更稳定）。

技巧 6：指定输出长度

DeepSeek 默认输出较长（中文场景常见）。

控制长度 Prompt：

请用 100-150 字概括以下文章的核心观点：

[文章内容]

或：

请分 3 段，每段 50 字，写一个简短的总结。

注意：用"字数范围"比"简短"更有效。

技巧 7：负面提示

告诉 DeepSeek 不要做什么。

Prompt：

请写一篇关于"AI 工具"的推荐文章。

要求：
- 列出 5 个工具
- 每个工具给 1 个具体使用场景

不要：
- 用空话（"AI 让生活更美好"）
- 重复标题
- 列举过多功能（每个工具聚焦 1 个场景）
- 用 emoji 装饰

负面提示显著提升输出质量。

技巧 8：角色对话

DeepSeek 在角色对话上特别强。

Prompt：

你是 [角色]，我有问题要问你。

角色设定：
- [身份]
- [性格]
- [背景]

你的回答要符合：
- 语气一致
- 不打破角色
- 给具体建议

现在开始对话：
[你的问题]

适用场景：

  • 模拟面试
  • 模拟客户对话
  • 历史人物对话
  • 心理咨询

技巧 9：迭代优化

DeepSeek 支持多轮对话，可以逐步优化输出。

第 1 轮：

请写一篇关于"远程办公"的短文。

第 2 轮：

请把开头改得更吸引人（增加钩子）。

第 3 轮：

请加 3 个具体的远程办公工具推荐。

第 4 轮：

请重新组织结构，让文章更清晰（用小标题分节）。

优势：逐步优化比"一次到位"质量高 5 倍。

🎯 6 个实战场景

场景 1：写公众号文章

DeepSeek 专用 Prompt：

你是公众号爆款作者，目标读者是 [读者]。

请写一篇 2000 字的公众号文章：
- 主题：[主题]
- 风格：口语化、有故事、有干货
- 结构：开头钩子 + 5 个要点 + 结尾引导
- 关键词：[关键词] 出现 3-5 次
- emoji：偶尔用，不要每段都有

场景 2：写小红书

Prompt：

你是小红书爆款作者。

请写一篇小红书笔记：
- 主题：[主题]
- 标题：18 字内，有 emoji
- 正文：300-500 字，分 3-5 段
- 风格：口语化、像朋友聊天
- 关键词：[关键词] 出现 3 次
- 结尾引导评论

场景 3：写代码

Prompt：

你是 [Python/Java/...] 高级工程师。

请编写：
- 功能：[功能描述]
- 输入：[输入示例]
- 输出：[输出示例]

要求：
- 加注释（中文）
- 异常处理
- 单元测试
- 代码风格：PEP 8

场景 4：翻译

Prompt：

请将以下 [英文] 翻译成 [中文]。

要求：
- 保留原意
- 流畅自然
- 专业术语准确
- 文末标注关键术语的英文原文

[内容]

场景 5：分析数据

Prompt：

请分析以下数据：

[数据 CSV/JSON/文本]

分析要求：
1. 数据基本情况（行数、字段、缺失值）
2. 主要趋势 / 异常
3. 关键洞察（3-5 条）
4. 行动建议

输出格式：Markdown 表格 + 文字说明

场景 6：学习新概念

Prompt：

我想深入理解 [概念]。

请：
1. 用 1 句话解释
2. 用 1 个例子说明
3. 列出 3 个常见误区
4. 推荐 3 个学习资源（书/网站/视频）
5. 给出"费曼学习法"自测题 3 道

  • ✅ 完全免费
  • ✅ 中文友好
  • ✅ 无需 API Key

技巧 2：用 DeepSeek + 简盒组合

简盒提示词优化器：

  • 输入烂提示词 → 输出专业提示词
  • 选「DeepSeek 模式」 → 自动适配

技巧 3：理解 DeepSeek 的"思考过程"

DeepSeek 输出时会显示思考过程（灰色文本）：

  • ✅ 一定要读
  • ✅ 检查是否有逻辑问题
  • ✅ 如果"想错了"，纠正它

举例：

思考：用户想要写一篇关于 Python 入门的文章，那么我应该先介绍什么是 Python，然后解释为什么学 Python，然后给学习路径……
等等，用户可能已经有编程基础，我应该先问……

这种自我反思让 DeepSeek 输出更准。

⚠️ DeepSeek 的局限

局限 1：无联网搜索

DeepSeek 不能：

  • ❌ 获取实时新闻
  • ❌ 搜索最新数据
  • ❌ 访问外部链接

替代：

  • 用 ChatGPT（有联网）
  • 用秘塔 AI 搜索（中文联网）
  • 用 New Bing

局限 2：英文略弱

DeepSeek 英文 比 GPT-4 略弱（特别创意写作）。

建议：英文任务用 ChatGPT。

局限 3：偶尔"幻觉"

DeepSeek 有时会编造事实。

解决：

  • 关键事实查证（百度/Google）
  • 让 DeepSeek 注明信息来源
  • 用"请谨慎，不要编造"提示词
