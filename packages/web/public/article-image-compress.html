📖 基础概念

一张图片为什么这么大？

1000万像素照片：~30 MB（未压缩）
JPEG（高画质）：~5 MB
JPEG（中画质）：~2 MB
WebP（高画质）：~1.5 MB
AVIF（高画质）：~800 KB

关键概念：

  • 有损压缩：丢细节，文件小（适合照片）
  • 无损压缩：保留所有信息，文件较大（适合图标、截图）

4 个影响图片大小的参数

| 参数 | 作用 |

|---|---|

| 分辨率 | 长 × 宽（像素） |

| 质量（Q 值） | 1-100，数字越小压缩越狠 |

| 格式 | JPEG/PNG/WebP/AVIF |

| 色深 | 8-bit / 16-bit（一般不用） |

🎯 4 种格式对比

JPEG vs PNG vs WebP vs AVIF

| 格式 | 压缩类型 | 透明度 | 动画 | 兼容性 | 体积 |

|---|---|---|---|---|---|

| JPEG | 有损 | ❌ | ❌ | 100% | 基准 |

| PNG | 无损 | ✅ | ❌ | 100% | 大 |

| WebP | 都有 | ✅ | ✅ | 95% | 小 30% |

| AVIF | 都有 | ✅ | ✅ | 80% | 小 50% |

| HEIC | 有损 | ✅ | ❌ | Apple | 小 30% |

选格式建议

| 场景 | 推荐格式 |

|---|---|

| 照片 | WebP（或 JPEG 兼容） |

| Logo / 图标 | PNG 或 WebP |

| 透明背景 | WebP（或 PNG） |

| 动图 | WebP 动图 |

| 网页图片 | AVIF / WebP |

| 苹果设备 | HEIC |

🔧 高级参数详解

1. 质量（Q 值）

| Q 值 | 画质 | 文件大小（1000万像素照片）|

|---|---|---|

| 100 | 无损（视觉） | 5 MB |

| 85 | 肉眼无差异（推荐） | 2 MB |

| 80 | 高质量 | 1.5 MB |

| 70 | 良好 | 1 MB |

| 60 | 一般 | 700 KB |

| 50 | 明显失真 | 500 KB |

经验法则：Q 80-85 是甜点（质量/体积平衡）。

2. 分辨率

Web 常用宽度：

  • 全屏背景：1920px
  • 卡片图片：800px
  • 缩略图：300px

经验法则：不超过展示尺寸的 2 倍（避免浪费，Retina 屏已够）。

3. 色深

| 色深 | 颜色数 | 用途 |

|---|---|---|

| 8-bit | 1670 万 | 绝大多数场景 |

| 16-bit | 280 万亿 | 专业摄影 |

建议：默认 8-bit。

4. Chroma Subsampling（色度采样）

JPEG 参数，影响颜色精度：

| 设置 | 适用 |

|---|---|

| 4:4:4 | 最高质量（无损颜色） |

| 4:2:2 | 高质量（颜色略降） |

| 4:2:0 | 标准（推荐） |

简盒默认 4:2:0。

5. 元数据

| 处理 | 建议 |

|---|---|

| EXIF（相机参数）| 摄影保留 / 网页删除 |

| GPS（位置）| 始终删除（隐私） |

| ICC（色彩）| 摄影保留 |

简盒默认删除 EXIF（减少体积 + 隐私），可选保留。

🔧 进阶技巧

1. 智能感知压缩

原理：AI 分析图片，重要区域（人脸、文字）高画质，不重要区域（背景）低画质。

效果：相同 Q 值，文件更小、画质更好。

2. 渐进式 JPEG

普通 JPEG：逐行显示（从顶到底）

渐进式 JPEG：先模糊再清晰

优点：网页加载时用户先看到模糊图，体验更好。

简盒图片工具箱 默认输出渐进式 JPEG。

⚠️ 常见误区

误区 1：压缩后画质一定变差

不一定！

  • 有损压缩：质量 < 100 时丢细节
  • WebP / AVIF：相同质量下比 JPEG 小 30-50%，画质不丢

建议：用 WebP / AVIF 替代 JPEG。

误区 2：分辨率越高越好

错！

  • 4K 显示器看 1080p 图，像素密度足够
  • 高分辨率 = 大文件 = 浪费
  • 拍 4K 留底，分享用 1080p/720p

误区 3：PNG 比 JPEG 小

错！

  • PNG 是无损格式，通常比 JPEG 大 3-5 倍
  • PNG 适合：图标、截图、透明图
  • JPEG 适合：照片

误区 4：上传在线压缩很安全

错！

  • 上传的图片可能永久存储
  • 可能被训练 AI
  • 可能被第三方访问
  • 隐私图片（家庭照片、个人信息）不要传

简盒图片工具箱 完全本地处理，文件不上传。

误区 5：AVIF 一定比 WebP 好

不一定！

  • AVIF 压缩率更高（~50% > WebP ~30%）
  • 但编码慢 5-10 倍（服务端压力大）
  • 浏览器兼容性 AVIF（80%）< WebP（95%）
  • 建议：WebP 优先，AVIF 渐进推进
