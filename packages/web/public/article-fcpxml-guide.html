📖 基础概念：什么是 FCPXML？

简单理解

FCPXML = Final Cut Pro XML = Apple 官方字幕/时间线交换格式

  • 不是视频文件，是 XML 文本文件（可以用记事本打开看）

  • 包含：时间码、文字内容、样式、轨道信息

  • 跨软件互通：Pr / 达芬奇 / 剪映专业版 都能识别

  • 无损：来回转换不丢帧、不丢字幕

🎯 常见场景详细操作

场景 1：剪映字幕 → FCPXML

背景

很多 Vlogger 在剪映里做字幕，因为：

  • 剪映的自动字幕识别比 Pr/FCPX 准（特别是中文）

  • 剪映的花字样式多（气泡、抖动、彩虹字）

但剪映的字幕不能直接用在 FCPX（格式不兼容）。

解决步骤

Step 1：从剪映导出字幕

  1. 剪映 → 选中视频 → 顶部「文本」→「识别字幕」

  2. 识别完成后 → 点字幕轨道右上角「···」→「导出字幕」

  3. 选 SRT 格式 → 保存到本地

💡 不要导出剪映的工程文件，剪映工程文件 (.draft) 不能转 FCPXML

Step 2：用简盒转换

  1. 打开 jianhebox.cn/fcpxml

  2. 拖入导出的 SRT 文件

  3. 输入格式：SRT · 输出格式：FCPXML

  4. 点击「开始转换」

  5. 下载 output.fcpxml 文件

Step 3：导入 FCPX

  1. 打开 Final Cut Pro

  2. File → Import → XML（或快捷键 ⌘⌥I）

  3. 选择下载的 .fcpxml 文件

  4. 字幕会自动出现在时间线上，时间码完全对齐

场景 2：Pr 字幕 → FCPXML

背景

Premiere Pro 用户想换到 FCPX，但 Pr 的字幕格式（.prtl 或 .mogrt）和 FCPXML 不兼容。

解决步骤

Step 1：从 Pr 导出 SRT

  1. Pr → 字幕面板 → 全选字幕

  2. 字幕 → 导出字幕 → SRT

  3. 保存

Step 2-3：同场景 1 的 Step 2-3

场景 3：Word/Excel 听写稿 → FCPXML

背景

你是会议记录员、采访记者、播客剪辑师，原始稿子在 Word/Excel 里，需要做成视频字幕。

解决步骤

Step 1：准备 Word 文档

每行一句话，例如：

你好，欢迎来到简盒


今天我们讲 FCPXML 转换

Step 2：用简盒自动加时间码

  1. 打开简盒 → 「FCPXML 字幕转换」

  2. 选 输入格式：DOCX/TXT · 输出格式：FCPXML

  3. 上传 Word 文件

  4. 设置每句字幕显示时长（默认 3 秒）

  5. 点转换 → 下载

场景 4：批量翻译字幕（中 → 英）

背景

你做完中文字幕，想快速出英文字幕版本。

解决步骤

⚠️ 常见问题

Q1：转换后字幕乱码？

原因：原文件编码不是 UTF-8（常见于 Windows 导出的 SRT）

解决：

  • 简盒默认 UTF-8 编码，导入时自动转码

  • 如果还是乱码 → 用记事本打开原文件 → 「另存为」→ 编码选 UTF-8

Q2：FCPX 导入后字幕位置不对？

原因：FCPXML 的 lane 属性指定轨道位置

解决：

  • 简盒默认 lane="1"（主字幕轨）

  • 想让字幕在视频上方改成 lane="-1"

  • 想让字幕双行显示改 lane="2"

Q3：转换速度慢？

原因：字幕超过 5000 条

解决：

  • 简盒纯浏览器处理，长字幕文件建议分批

  • 一次最多 3000 条（2 小时视频）转换稳定

Q4：转换后字幕样式丢失？

原因：原文件不含样式信息（如 SRT 格式）

解决：

  • 简盒提供 4 种预设样式，应用后样式统一

  • 想保留原样式 → 用剪映/Pr 的 「带样式导出」 选项

FCPXML 版本对照表

| FCPX 版本 | FCPXML 版本 | 备注 |

|---|---|---|

| FCPX 10.4 | 1.7 | 老版本 |

| FCPX 10.5 | 1.9 | 加入 Object 标签 |

字幕文件 vs FCPXML

| 特性 | SRT | VTT | FCPXML |

|---|---|---|---|

| 文字 | ✅ | ✅ | ✅ |

| 时间码 | ✅ | ✅ | ✅ |

| 字体样式 | ❌ | 部分 | ✅ |

| 位置控制 | ❌ | 部分 | ✅ |

| 多轨 | ❌ | ❌ | ✅ |

| FCPX 原生 | ❌ | ❌ | ✅ |

结论：要在 FCPX 里用，FCPXML 是唯一选择。
